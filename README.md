# Изгиб Питона

Классическая «Змейка» на Python и Pygame. Управление — стрелками клавиатуры.
Змейка проходит через края поля, растёт при поедании яблок и начинает заново
при столкновении с собой. Яблоки появляются только в свободных клетках.
После заполнения всего поля начинается новая игра.

## Запуск

Для зависимостей из задания рекомендуется Python 3.11.
Распакуйте архив и выполните команды из папки проекта:

```console
python -m venv venv
venv\Scripts\activate
python -m pip install -r requirements.txt
python the_snake.py
```

Чтобы выйти из игры, закройте окно.

## Проверки

```console
python -m pytest
python -m flake8 the_snake.py
```

В проекте сохранены исходные тесты задания и добавлены проверки игровых правил:
переходов через края, роста, запрета разворота, размещения яблок, столкновений,
отрисовки хвоста, заполнения поля и выхода из игры.
